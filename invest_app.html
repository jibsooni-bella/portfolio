종목 추가

ETF/국내주식은 자동 가격 조회가 되고, 금현물계좌는 현재가를 1g 가격으로 직접 입력하면 돼.
금현물 입력 예시
계좌: 금현물계좌 / 종목명: KRX 금현물 / 티커: KRX-GOLD / 수량: 9 / 현재가: 금 1g 가격 직접 입력
배당 입력 방식
1) 월/분기/반기/연배당이면 배당주기와 1회 주당 배당금 입력
2) 올해 일부 분기만 받는 경우는 직접입력 선택 후 올해예상주당배당 입력
예: TIGER 200 총 14,960원 / 22주 = 680원 → 직접입력 + 680
마지막 업데이트: -
